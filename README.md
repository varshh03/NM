# 📅 Event Scheduler - Naan Mudhalvan

## 📌 Overview  
**Event Scheduler System** developed as part of the **Naan Mudhalvan initiative**. It helps in efficiently managing and organizing events by allowing users to schedule, track, and manage event activities in a structured way.

---

## 🚀 Features  
- 📅 Create and manage events  
- ⏰ Schedule date and time for events  
- 📝 Add event details and descriptions  
- 🔔 Reminders and notifications (optional)  
- 📊 Organized view of upcoming and past events  

---

## 🛠️ Tech Stack  
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python / Node.js (based on your implementation)  
- **Database**: MySQL / MongoDB  
- **Framework (optional)**: Flask / Express
